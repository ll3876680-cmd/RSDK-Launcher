# RSDK-Launcher
An Origins-Like launcher for Sonic 1 forever, Sonic 2 absolute and Sonic CD (2013)
# Installation
1-Download the RSDK launcher from the official repo

2-Put the Games's files in this specific path, Well'll take Sonic 1 forever as an example:"Downloads/RSDK Launcher/S1f/(the Sonic 1 Forever game files)


3-Enjoy :D!!!!!
# Not important
S1f stands for Sonic 1 Forever, S2A stands for Sonic 2 Absolute
